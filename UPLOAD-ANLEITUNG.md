# Anleitung: Repository auf GitHub hochladen

## Empfohlen: GitHub Desktop

1. Entpacke die ZIP-Datei vollständig.
2. Installiere GitHub Desktop von https://desktop.github.com/, falls es noch nicht installiert ist.
3. Öffne GitHub Desktop und melde dich über den Browser bei GitHub an. Teile kein Passwort und keinen Token mit Dritten.
4. Wähle **File → Add local repository**.
5. Wähle den entpackten Ordner `deutschland-flieht-github-paket`.
6. Falls GitHub Desktop meldet, dass dort noch kein Repository liegt, wähle **create a repository**.
7. Als Namen kannst du beispielsweise `deutschland-flieht` verwenden.
8. Erstelle den ersten Commit, zum Beispiel mit der Beschreibung `Initial import der beiden Kampagnenseiten`.
9. Klicke auf **Publish repository**.
10. Lasse **Keep this code private** aktiviert, wenn das Repository nicht öffentlich sichtbar sein soll.

## Alternative: GitHub-Webseite

1. Entpacke die ZIP-Datei vollständig. Lade nicht nur die ZIP-Datei hoch, da GitHub sie nicht automatisch als Repository-Inhalt entpackt.
2. Öffne https://github.com/new und erstelle ein leeres Repository.
3. Öffne im neuen Repository **Add file → Upload files**.
4. Ziehe den Inhalt des entpackten Ordners in das Upload-Feld. Falls GitHub wegen der
   Dateianzahl nicht alles auf einmal annimmt, lade die beiden Webseiten-Ordner
   nacheinander hoch oder verwende GitHub Desktop.
5. Prüfe vor dem Bestätigen, dass `README.md`, `UPLOAD-ANLEITUNG.md` und der Ordner `webseiten` sichtbar sind.
6. Bestätige den Upload mit **Commit changes**.

## Spätere Änderungen

Öffne das Repository in GitHub Desktop, kopiere die geänderten Dateien in den lokalen
Ordner, erstelle einen Commit und klicke anschließend auf **Push origin**.
